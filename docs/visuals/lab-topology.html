Admin path: set up once

  1. Admin creates project prod-chat (2 GPU) in the Run:ai UI
  2. Run:ai makes the namespace and quota
  3. The controller sees it and configures BNK
  4. The ML engineer deploys a model, and Run:ai places it on a GPU fraction

Request path: every call

  1. The app calls prod-chat.ai.acme.lab
  2. BNK identifies the tenant and checks its limit
  3. The Endpoint Picker picks the best replica
  4. The GPU does the work, and BNK counts the tokens
